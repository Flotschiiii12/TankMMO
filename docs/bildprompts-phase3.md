# Treadfront: Bild-Prompts Phase 3 (Böden, Props, Landmarken, Piktogramme, Abzeichen, Wappen)

Gleiche Arbeitsweise wie Phase 1/2: **immer das Stil-Referenzbild `00_stil_referenz.jpg` anhängen**, pro Prompt 2-3 Versuche, besten Bogen mit dem angegebenen Dateinamen in `/root/treadfront-assets/` ablegen. Ich schneide aus und baue ein.

**Reihenfolge nach Nutzen:**
1. Prompt 11-14 aus Phase 2 (Fahrzeuge Stufe 4-10, 35 von 50 Fahrzeugen fehlen noch).
2. Prompt 32-34 (Piktogramme): ersetzen die Platzhalter-Symbole in der ganzen Oberfläche.
3. Prompt 20-22 (Böden) und 23-26 (Props): jede Karte bekommt ihren eigenen Look.
4. Prompt 27-31 (Landmarken), 35-38 (Abzeichen, Wappen, Embleme): Feinschliff.

Böden brauchen keine dunkle Bühne, sondern füllen die Zelle komplett; bitte darauf achten, dass die Kacheln keine eigenen Rahmen oder Vignetten haben.
